# Rotation Pilot

Tank and DPS rotation helper for WoW Forever. Version 0.8.9 shows the next three actions and can recommend defensives, dispels, and consumables.

## Installation

Copy the `ProtPilotOffense` folder into the Forever client's `Interface/AddOns` folder. Reload the UI with `/reload`. Open the settings with `/rpilot` or `/ppoff`.

See the [addon guide](ProtPilotOffense/README.md), [tank ability coverage](ProtPilotOffense/TANK-ABILITIES.md), and [third-party notices](ProtPilotOffense/THIRD_PARTY.md).
